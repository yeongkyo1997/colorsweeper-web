# ColorSweeper Web

안드로이드 퍼즐 게임 **ColorSweeper**를 React로 다시 만든 웹 버전입니다. 규칙과 퍼즐 생성 방식은 원본 게임(1.4.5)의 규칙 코드를 분석해 맞췄습니다.

## 게임 방법

모든 빈칸을 알맞은 색으로 칠하면 클리어입니다. 칠한 칸에는 단서가 나타납니다.

- **숫자**: 자신을 뺀 주변 8칸 중 자신과 같은 색인 칸의 개수
- 틀린 색을 칠하면 하트가 하나 줄고, 하트 3개를 모두 잃으면 게임 오버
- 모든 퍼즐은 추측 없이 논리만으로 풀리도록 생성됩니다

### 조작

| 기능 | 설명 | 단축키 |
|---|---|---|
| 색 선택 | 팔레트에서 색을 고름 | `1`–`5` |
| X 표시 | 그 칸에 올 수 없는 색을 메모 | `X` |
| 자동 X | 숫자가 충족된 칸을 두 번 누르면 주변 빈칸에 X | 더블 클릭 |
| 스케치 | 가정을 세우고 칠해 보는 모드(판정·하트 영향 없음) | `S`, 되돌리기 `Z` |
| 힌트 | 지금 추리로 확정할 수 있는 칸 표시 | `H` |

## 규칙

### 칸 규칙
| 규칙 | 설명 |
|---|---|
| 표준 | 숫자 = 주변 8칸 중 같은 색 칸 수 |
| 기사 | ♞ 칸은 나이트 이동 칸 중 정확히 1칸만 같은 색 |
| 방향 | 숫자+화살표(상하좌우): 그 방향으로 판 끝까지 같은 색 칸 수 |
| 커플 | 삼각형이 가리키는 이웃 칸과 (보이지 않는) 숫자가 같음 |
| 대칭 | 화살표 방향의 짝 화살표 칸까지(양 끝 포함) 색이 대칭 |
| 패턴 | 같은 룬 칸들은 주변 8칸의 "같은 색인가" 배치가 같음 |

### 라인 규칙 (판 위·왼쪽에 행·열 단서)
| 규칙 | 설명 |
|---|---|
| 연속 | 그 줄에서 같은 색이 이어진 가장 긴 길이 |
| 블록 | 그 줄에서 표시된 색 블록의 개수 |
| 듀오 | 그 줄에서 길이가 정확히 2인 블록의 개수(기울임 숫자) |

### 특수 규칙
| 규칙 | 설명 |
|---|---|
| 은폐 | 풀리는 한 최대한 많은 숫자 단서를 `?`로 가림 |
| 미리보기 | 일부 빈칸은 칠하기 전부터 숫자가 보임 |
| 위장 | 숫자 단서의 절반쯤이 2배로 표시됨(짝수 k는 k 또는 k/2) |

## 모드

- **스테이지**: 14개 월드 × 8스테이지. 한 월드에서 4개를 클리어하면 다음 월드가 열립니다.
- **데일리**: 날짜마다 정해지는 쉬움·보통·어려움 퍼즐. 난이도마다 하루 한 번, 클리어하면 스트릭 +1, 실패하면 0.
- **랜덤**: 판 크기(6–12), 색 수(2–5), 칸·라인·특수 규칙을 골라 만드는 퍼즐.

진행 기록은 브라우저(localStorage)에 저장됩니다.

## 실행

Node.js 18 이상이 필요합니다.

```bash
npm install
npm run dev      # 개발 서버 (http://localhost:5173)
npm run build    # dist/ 에 배포용 빌드
npm test         # 규칙 검증 + 풀이 가능성 검사
```

## 구조

```
src/
  engine/
    grid.js       좌표·방향·난수 헬퍼
    solver.js     제약 전파 풀이기 (규칙별 제약, 힌트)
    generate.js   퍼즐 생성기 (원본 NeoPuzzleBuilder 순서를 따름)
    rules.js      규칙 설명, 스테이지·데일리 설정
  screens/        타이틀, 스테이지, 데일리, 랜덤 설정, 퍼즐 화면
  storage.js      localStorage 저장
scripts/
  verify-rules.mjs   생성된 단서가 원본 규칙 정의와 맞는지 검사
  solvability.mjs    규칙·조합별로 힌트만 따라 끝까지 풀리는지 검사
```

## 원본과 다른 점

- 한 퍼즐에 칸 규칙은 하나만 쓸 수 있습니다(원본은 여러 개를 섞을 수 있음).
- 난이도별 추론 깊이 없이 한 단계 추론기만 사용합니다.
- 스테이지 퍼즐은 원본의 미리 만든 퍼즐이 아니라 고정 시드로 생성합니다.
- 광고·결제·로그인·재화·테마·업적과 원본 그림·소리는 없습니다.
