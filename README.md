# ColorSweeper Web

안드로이드 퍼즐 게임 ColorSweeper의 규칙을 React로 다시 만든 웹 버전입니다.

숫자는 자신을 뺀 주변 8칸 중 자신과 같은 색인 칸의 개수입니다. 단서로 모든 빈칸의 색을 추리해 칠합니다. 모든 퍼즐은 추측 없이 논리만으로 풀리도록 생성됩니다.

## 기능

- 규칙: 표준, 기사, 방향, 커플, 대칭, 패턴(칸 규칙) · 연속, 블록, 듀오(라인 규칙) · 은폐, 미리보기, 위장(특수 규칙)
- 모드: 스테이지(14개 월드), 데일리(난이도별 하루 1판, 스트릭), 랜덤(규칙 직접 선택)
- 조작: X 표시, 스케치(가정 풀이), 힌트, 하트 3개

## 실행

```bash
npm install
npm run dev
```

## 구조

- `src/engine/` — 제약 전파 풀이기, 퍼즐 생성기, 규칙 정의
- `src/screens/` — 타이틀, 스테이지, 데일리, 랜덤 설정, 퍼즐 화면
